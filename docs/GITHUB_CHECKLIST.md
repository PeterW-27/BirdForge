# Public GitHub competition checklist

- [ ] Create a public GitHub repository under your team account.
- [ ] Make at least three genuine commits and confirm they appear in the public repository.
- [ ] Do not present AI-assisted scaffold code as entirely student-authored.
- [ ] Students create all inline source comments themselves.
- [ ] Record AI assistance in `AI_USAGE.md` and update it as you continue.
- [ ] Test browsing, ordinary checkout, bulk direct checkout, custom order quote, reference image, recycling, Forge Board, Work Tickets, and mobile layouts.
- [ ] Integrate the actual announced surprise feature during the event.
- [ ] Submit an accessible repository URL to the designated email before the cutoff, with team number in the subject and member names below the link.
- [ ] Make no further repository or project changes after the official submission cutoff.
