# Code comment handoff

No AI-authored inline source comments are included. The competition expects students to write source comments themselves. When the final design is settled, consolidate each source file into a numbered worksheet with blank student comment slots. The student fills the explanations and returns them. Then comments can be transferred verbatim to the matching source locations, with a diff review to confirm no behavior changed.

Suggested areas for independent study and student-written comments: catalog and image routing, cart state, recycling request and metal collection, direct-order validation, reference-image restrictions, sorting and splitting work tickets, ticket completion persistence, modal navigation, responsive design boundaries, and standalone packaging.
